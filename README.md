# Word & Readability Telemetry

A fast, single-file word analysis tool that delivers real-time readability metrics, keyword density tracking, and time estimates.

Built with clean UI, responsive layout, and zero dependencies.

---

## Features

- Live word, character, sentence, and paragraph counts  
- Automated readability grade calculation  
- Reading and speaking time estimation  
- Keyword density tracking  
- Dark and light theme toggle  
- Fully responsive design  
- URL-based state sharing  
- Copy and social share options  
- Accessibility-friendly structure  

---

## Tech Stack

- HTML5  
- CSS3 with custom properties and grid  
- Vanilla JavaScript  
- Google Fonts (Inter, JetBrains Mono)  

No frameworks. No build tools. No dependencies.

---

## Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/word-readability-telemetry.git
````

Open the project:

```bash
cd word-readability-telemetry
open index.html
```

That’s it.

---

## Customization

You can easily adjust:

* `KEYWORDS` array for density tracking
* `READING_SPEED` and `SPEAKING_SPEED` values
* Add new metrics inside `analyzeText()`

The entire application runs in a single `index.html` file.
